DESCRIPTION
  Compares a shadow built from supabase/migrations with a live database (the local database by default, or the one --remote selects). Declarative files under supabase/schemas are not part of this baseline. Output is printed by default; in normal mode, -f names and saves the complete diff as a migration and does not filter objects. Explicit --from/--to output is flattened review SQL, not a portable apply script.

TARGET
  Local by default. Pass --remote for the linked project, or --remote=<ref|branch|url>.

USAGE
  supabase db diff [flags]

FLAGS
  --use-migra                    Use migra to generate schema diff.
  --use-pgadmin                  Use pgAdmin to generate schema diff.
  --use-pg-delta                 Use pg-delta to generate schema diff.
  --strict-coverage              Fail when bundled pg-delta finds schema objects it cannot manage instead of leaving them unmanaged.
  --from string                  Diff from local, migrations, remote (always the linked project), a project ref, a branch, or a Postgres URL.
  --to string                    Diff to local, migrations, remote (always the linked project), a project ref, a branch, or a Postgres URL.
  --output, -o string            Write flattened explicit diff SQL to a file for review; this is not a portable apply script.
  --remote[=<ref|branch|url>]    Target a remote database: the linked project, or --remote=<ref|branch|url>.
  --file, -f string              In normal mode, names and saves the complete schema diff as a new migration; it does not filter objects. Ignored with --from/--to.
  --schema, -s string            Comma separated list of schema to include.

PERMISSIONS
  Scoped access token:
    May be required (with --remote, --from or --to):
      database_write
      database_pooling_config_read
    May be required (with --remote, --from=linked|remote or --to=linked|remote):
      projects_read
    May be required:
      branching_development_read for a preview branch
        or branching_production_read for the main branch
    Optional, with --remote, --from or --to (command still runs without these):
      database_network_bans_read
      database_network_bans_write
      project_admin_read
