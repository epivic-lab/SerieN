# 6A.11 — isolated adversarial harness

Only synthetic PostgreSQL17; no external DSN, Supabase, staging or simulator.
Run sequentially: Docker uses vfs and this workspace has a small disk. The normal
launcher accepts one broker only. A second process is started explicitly *inside
the private broker container* for the unsupported aggregate-budget diagnostic;
this is not a second host/container isolation test.

Prerequisites: Docker local Unix socket, pinned PG17 and Node24 images used by
6A.9/10, Python jsonschema, OpenSSL, host Node24, existing lab `pg` installation
from its approved package-lock, test-only Playwright and `/usr/bin/chromium`.
No application dependency is added. Runner ignores DOCKER_HOST/CONTEXT/TLS env,
creates internal SQL network, separate loopback HTTP ingress, UID/mount isolation,
SCRAM and verified TLS. Bootstrap trust is limited to the isolated supervisor;
remote peers start only after TLS/SCRAM is installed. Root/DDL/Docker belong only
to the out-of-band supervisor, not to public ingress or private broker.

From repository root:

```sh
SERIEN_DB_EVIDENCE=/workspace/work/6A11/final PLAYWRIGHT_MODULE=/workspace/work/6A8/tools/node_modules/playwright python3 tests/db/6A11/run.py
```

Reuses immutable `6A10/fixture.py` and `sql_checks.py` for185 O01–O14 assertions,
then runs111 integrated/browser adversarial checks on C/D Auth0 plus one diagnostic. `finish` compares
all original historical records, no snapshot/receipt updates/deletes. Runtime
copy is read-only; `sql-probes.js` is copied only into that disposable copy and
never served over HTTP. Fault hooks/DDL/permission changes belong only to fixture.
Cleanup removes exact generated containers/networks/volumes and private CA keys;
cleanup.json asserts removal, independent of pass/fail. No global prune/reset.

Three defect repros, same actual gateway/PG, expected FAIL before hardening:

```sh
SERIEN_REPRO_ONLY=1 SERIEN_DB_EVIDENCE=/workspace/work/6A11/repro python3 tests/db/6A11/run.py
SERIEN_DB_EVIDENCE=/workspace/work/6A11/legacy-green-final python3 tests/db/6A11/legacy-repro.py
python3 tests/db/6A11/run.py --replicas 2
```

Last command must reject before creating resources. Legacy repro reuses unmodified
6A.6 runner/fixture by replacing exactly its child test entrypoint in memory;
actual WebCrypto→HTTP→SQL adapter, no mocked execute/provision. Its legacy/Auth
scope is explicitly separate from ownerless certification. Calls transport.close
in finally. RED observations were recorded before adding string nonce guards.

Full regressions: run `tests/db/{6A3,6A4,6A5,6A8,6A6,6A9,6A10}/run.py`
**one at a time**, supplying separate SERIEN_DB_EVIDENCE and PLAYWRIGHT_MODULE as
above. Run capability-gateway/security.test.js and browser.test.js (NODE_PATH to
test-only Playwright), transaction-core/envelope.test.js, history-access/protocol.test.js,
`npm test`, `python3 -m unittest discover -s tests -p '*_test.py'`, `npm run build`.

`collect-evidence.py` collects these named work directories, checks observed counts
and results, derives percentiles separately for each load profile, and copies
sanitized artifacts; it never contacts services. Integrated final script scans
actual generated private values in results/audit/metrics/load-profiles and in
served browser assets. Pattern/scope/hash/doc checks:

```sh
python3 tests/db/6A11/verify-invariants.py
```

Historical red/green files are evidence, not regenerated by collection. Failed
harness attempts (port reassignment, omitted transport.close/disk, time-window
oracle drift) are disclosed in run-provenance.json and not counted as passing.
Signals only target exact test process/container IDs. Timing has tolerance around
5s/15s; ordinary latency is never mixed with intentionally locked/faulted traffic.

A successful run certifies only the single-broker lab. Two workers open32 actual
SQL connections against a16 local cap: that budget criterion FAILS and is never
counted as PASS. No distributed coordinator or SQL privileges were introduced.
Host/store/DB-loss/PITR, managed Supabase, other browsers and full R1 visuals/perf
remain NOT VERIFIED. No authorization for6A.12,6B or production.
